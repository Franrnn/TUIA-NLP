# Revisión de `queries.json`

`queries.json` es el conjunto de evaluación del TP2: 18 consultas y, para cada una, los libros del corpus que se consideran una buena respuesta. Con él se va a calcular precision@k para TF-IDF, cada modelo de embeddings y el azar.

Este documento es para que **otra persona del grupo revise las listas antes de hacer la evaluación**. La primera versión la armó un solo lector, y un segundo par de ojos reduce el sesgo.

## Cómo revisar

1. Para cada consulta, leer el **criterio** y los libros marcados como relevantes (más abajo están con el comienzo de su sinopsis).
2. Preguntarse dos cosas:
   - ¿Sobra alguno? (un libro que no responde a la consulta según el criterio)
   - ¿Falta alguno? Para esto hay que mirar el resto del corpus: `data/libros.csv` tiene las 150 sinopsis (se abre con Excel o con pandas). No hace falta releer todo para cada consulta; alcanza con una lectura general y anotar al pasar.
3. Corregir directamente `queries.json`: agregar o quitar objetos `{"id": ..., "titulo": ...}` de la lista `relevantes`. El `id` es el de `libros.csv`.
4. Anotar al final de este archivo qué se cambió y por qué (sirve para el informe y la defensa).

## Reglas

- **No decidir la relevancia mirando qué devuelve un buscador.** Ni `buscar(...)`, ni los rankings de la Parte D del notebook (que muestran tres de estas consultas), ni TF-IDF. Si se marca como relevante lo que el modelo encontró, la métrica deja de medir algo. Se decide leyendo las sinopsis.
- **Después de calcular precision@k, `queries.json` no se toca más.** Si un resultado sorprende, se explica en el informe; no se corrige el conjunto para que dé mejor.
- No hace falta que todas las consultas tengan muchos relevantes. Es válido que una tenga 2 o 3.
- `q17` y `q18` están pensadas para **no compartir ninguna palabra** con sus libros relevantes (campo `sin_palabras_en_comun`). Si se les cambia el texto, hay que volver a comprobarlo.

## Limitaciones conocidas de esta versión

- La relevancia se juzgó por la sinopsis, no por el libro.
- En las sinopsis largas se leyó solo el comienzo (entre 800 y 1.100 caracteres). Un libro relevante por algo que aparece al final pudo quedar afuera.
- Hay dos libros con la misma sinopsis: "Los muchos mundos de Poul Anderson" I y II.
- Casos dudosos a mirar con atención: si una plaga zombi cuenta como "enfermedad" (`q02`), si las revistas cuentan como "antologías" (`q11`, hoy no cuentan), y si "La trampa" / "El rival oscuro" (Star Wars) deberían estar en "guerras espaciales" (`q10`, hoy no están porque su sinopsis no habla de batallas).
